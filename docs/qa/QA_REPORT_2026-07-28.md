## 알려진 배포 위험

현재 바이너리에는 Authenticode 서명이 없어 Windows SmartScreen 경고가 표시될 수 있다. 릴리스에는 `SHA256SUMS.txt`와 기계 판독 가능한 manifest를 제공하며, 앱은 적용 전에 GitHub asset digest와 파일 버전을 검증한다. GitHub 자산과 digest는 같은 계정 신뢰 경계에 있으므로 독립 서명 manifest는 향후 강화 항목이다.

`dotnet format --verify-no-changes`는 프로젝트가 기존부터 유지한 다국어 초기화 테이블과 압축된 이벤트 구문을 기본 포매터가 여러 줄로 바꾸려 하므로 통과하지 않는다. 이 검사는 저장소나 CI의 품질 게이트가 아니며, 이번 변경에서는 기존 코드 스타일과 번역 diff를 보존했다.
