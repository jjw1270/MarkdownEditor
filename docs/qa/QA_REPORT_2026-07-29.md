# MarkDownEditor 1.3.1 QA Report

검증일: 2026-07-29

대상: Windows x64 설치판과 완전 포터블판

## 결론

릴리스 게이트를 모두 통과했다. 실제 WebView 화면, 파일 저장과 외부 변경, 설치·제거, 포터블/설치판 업데이트 및 실패 원복을 확인했다. QA 중 확인된 제품 결함은 수정하고 같은 경로를 회귀 테스트로 고정했다.

## QA에서 수정한 결함

1. 같은 파일의 비동기 저장이 겹치면 오래된 저장이 마지막에 끝나 최신 입력을 덮을 수 있었다. 파일별 저장 큐와 요청 번호를 추가했다.
2. 자체 저장 이벤트를 2초 동안 무시해 그 사이 발생한 실제 외부 변경도 놓쳤다. 시간 기반 억제를 제거했다.
3. Markdown HTML이 미리보기 DOM에 그대로 들어가 script 이외의 활성 콘텐츠가 남을 수 있었다. DOM 정화와 CSP 제한을 추가하고 Mermaid를 `strict` 모드로 고정했다.
4. Windows 경로 비교가 대소문자를 구분해 같은 파일이 여러 탭에 열릴 수 있었다. 경로 비교를 일관되게 바꿨다.
5. 비 ASCII 제목의 heading ID가 비거나 손상될 수 있었다. Unicode 문자·숫자·결합 문자를 보존한다.
6. 업데이트 ZIP 검사가 ADS, symlink/reparse point, 끝점·공백과 일부 비정규 경로를 충분히 거르지 못했다. 검사 범위를 확대했다.
7. 업데이트 전에 압축 파일 크기만 확인해 실제 해제 공간 부족을 놓칠 수 있었다. 전체 해제 크기를 계산해 대상 볼륨을 검사한다.
8. 타이틀바 테스트가 이전 실행의 최대화 상태를 물려받으면 좌표가 흔들렸다. 시작 상태를 복원한 뒤 검사하도록 하네스를 안정화했다.
9. 자동 캡처에서 마우스 hover 툴팁이 README 이미지에 섞였다. 캡처 전에 포인터를 안전 영역으로 이동한다.

## 릴리스 산출물

로컬 사전 배포 빌드의 `SHA256SUMS.txt`와 `release-manifest.json`이 실제 Setup·ZIP의 크기와 SHA-256에 일치했다. GitHub Actions가 만드는 공개 자산은 빌드 시각이 달라질 수 있으므로 릴리스에 함께 올라가는 체크섬과 manifest를 기준으로 확인한다. manifest는 앱 1.3.1, win-x64, .NET SDK 10.0.302, Fixed WebView2 Runtime 150.0.4078.65를 기록한다.

## 남은 위험

바이너리에는 Authenticode 서명이 없어 Windows SmartScreen 경고가 표시될 수 있다. 릴리스는 `SHA256SUMS.txt`와 manifest를 제공하고 앱은 적용 전에 GitHub asset digest와 파일 버전을 검사하지만, 자산과 digest가 같은 계정 신뢰 경계에 있으므로 독립 서명 manifest는 향후 강화 항목이다.

Fixed WebView2 Runtime은 재현 가능한 포터블 배포를 위해 버전을 고정한다. 이번 릴리스에는 검증 시점의 최신 버전인 150.0.4078.65를 넣었지만, 이후 보안 업데이트는 다음 앱 릴리스에 반영해야 한다.

`marked` 12.0.2는 확인한 GitHub Advisory Database에 알려진 해당 버전 취약점이 없지만 최신 메이저 버전은 아니다. 렌더 결과에는 별도 DOM 정화를 적용했으며, 메이저 업그레이드는 호환성 검증을 포함한 후속 유지보수 항목으로 남긴다.
