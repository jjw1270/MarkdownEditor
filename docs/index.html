왜 만들었나

윈도우에서 .md 파일 하나 보려면 대개 설치형 프로그램을 깔거나, 브라우저 확장을 붙이거나, VS Code 같은 코드 에디터를 띄워야 합니다. 이 앱은 그 셋 다 필요 없습니다. 마크다운 뷰어가 먼저이고, .md 기본 프로그램으로 지정해두면 README·명세서·메모 폴더를 탐색기에서 더블클릭하는 것만으로 렌더링된 문서를 볼 수 있습니다. 편집이 필요하면 Ctrl+E 한 번이면 됩니다.

  • 설치 없음 — 압축만 풀면 끝. USB에 담아 다른 PC에서 그대로 써도 됩니다.
  • 흔적 없음 — 설정·캐시가 레지스트리나 %AppData%가 아니라 실행 파일 옆에만 남습니다.
  • 오프라인 동작 — 렌더링·코드 하이라이팅·다이어그램 전부 로컬에서 처리됩니다.
  • 무료 · 오픈소스 — MIT 라이선스.

무료 마크다운 뷰어, 가벼운 Typora 대안, md 파일 여는 프로그램을 찾고 있었다면 바로 그 용도로 만든 앱입니다.

핵심 기능

읽기에 최적화하고, 쓰기는 필요할 때 바로 꺼낼 수 있게 만들었습니다.

📂 더블클릭 = 바로 열림

.md 기본 연결 프로그램으로 지정하면 탐색기에서 더블클릭하는 순간 열립니다. 드래그&드롭도 지원합니다.

🗂 창은 하나, 문서는 탭

파일을 스무 개 열어도 창이 스무 개 뜨지 않습니다. 모두 한 창의 탭으로 모이고, 드래그로 순서를 바꿀 수 있습니다.

🧜 mermaid 다이어그램

GitHub·GitLab과 동일한 문법의 플로차트·시퀀스·간트를 오프라인으로 렌더링합니다. 테마에 맞춰 색도 바뀝니다.

🌙 다크 / 라이트 테마

Windows 제목표시줄까지 함께 전환되고, 한 번 고르면 다음 실행에도 기억합니다.

📄 PDF 내보내기

버튼 한 번(Ctrl+P)으로 미리보기 그대로 PDF 저장. 별도 프린터 설정이 필요 없습니다.

✏️ 서식 바

굵게·제목·목록·체크박스·표·링크를 버튼 한 번에. 마크다운 문법을 몰라도 문서를 씁니다.

🔗 모든 링크가 동작

.md는 새 탭, 웹 링크는 브라우저, 폴더는 탐색기로. 문서 간 앵커 이동과 뒤로/앞으로 탐색까지 지원합니다.

💾 자동 백업 & 복구

저장 안 한 변경을 30초마다 스냅샷해 두었다가, 비정상 종료 후 재실행하면 복구를 제안합니다.

설치하기

설치 프로그램 없음, 관리자 권한 없음. 3단계, 1분이면 끝납니다.

  1. MarkDownEditor-standalone.zip 내려받기 — 이 링크는 항상 최신 버전을 가리킵니다 (약 331 MB).
  2. 쓰기 가능한 아무 폴더에 압축 해제 — C:\Tools\MarkDownEditor, 바탕화면, USB 메모리 어디든 됩니다.
  3. MarkDownEditor.exe 실행.
  4. (핵심) .md 기본 프로그램으로 지정 — 탐색기에서 아무 .md 파일 우클릭 → 연결 프로그램 → 다른 앱 선택 → MarkDownEditor.exe 선택 (목록에 없으면 내 PC에서 앱 선택) → 항상 이 앱을 사용하여 .md 파일 열기 체크. 이후로는 더블클릭만으로 열립니다.
처음 실행할 때 뜨는 파란 SmartScreen 창은 정상입니다 — 코드 서명이 없는 실행 파일이라 Windows가 “Windows의 PC 보호” 경고를 띄웁니다. 추가 정보 → 실행을 누르세요. 한 번만 뜹니다. 서명 없는 파일이 꺼려진다면 소스에서 직접 빌드해도 명령 두 줄이면 됩니다.
업데이트 — 이 페이지에 다시 올 필요 없습니다. 새 버전이 나오면 앱 타이틀바 버전 표시 옆에 빨간 점이 뜨고, 버전 클릭 → 업데이트하기 한 번이면 앱 안에서 내려받아 재시작합니다. 설정·열려 있던 탭·세션은 그대로 유지됩니다.
삭제 — 폴더를 지우면 끝입니다. 레지스트리에도 %AppData%에도 “앱 및 기능” 목록에도 아무것도 남기지 않습니다.
요구 사항 — Windows 10 / 11 (64-bit). WebView2 런타임이 앱에 번들되어 있어 별도 설치가 필요 없습니다.

데이터 & 프라이버시

문서는 이 PC를 벗어나지 않습니다.

  • 문서·설정을 클라우드로 보내지 않습니다. 렌더링·편집·내보내기 전부 로컬에서만 이뤄집니다.
  • 유일한 네트워크 접근은 자동 업데이트입니다 — GitHub API에서 최신 버전 번호만 익명으로 조회하고, 사용자가 직접 업데이트를 실행한 경우에만 릴리즈 파일을 내려받습니다.
  • 테마·언어 설정과 WebView2 캐시는 실행 파일 옆에만 저장됩니다. 레지스트리를 건드리지 않습니다.
  • 미리보기 안의 인라인 스크립트는 콘텐츠 보안 정책(CSP)으로 차단되어, 문서를 여는 것만으로 코드가 실행되지 않습니다.
