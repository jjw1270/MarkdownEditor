# 스펙: 자동 업데이트

> 상태: 포터블판·설치판 구현 및 보안 검증 완료. 현재 기준 버전은 `1.3.1`이며,
> 배포·데이터 경계의 상위 문서는 [`DESIGN.md`](../DESIGN.md)다.

## 1. 공통 확인 흐름

- 앱이 준비된 뒤 GitHub 최신 릴리즈 API를 익명으로 1회 확인한다.
- 사용자는 타이틀 옆 버전 메뉴에서 언제든 다시 확인할 수 있다.
- 릴리즈 태그는 정확히 `vMAJOR.MINOR.PATCH` 형식이어야 한다.
- 실행 중인 배포 형태에 따라 자산 이름을 고른다.
  - 포터블판: `MarkDownEditor-standalone.zip`
  - 설치판: `MarkDownEditor-Setup-x64.exe`
- 자산이 없거나 규약을 만족하지 않으면 자동 적용하지 않는다. 수동 확인에서는 최신 릴리즈
  페이지를 열어 사용자가 상태를 확인할 수 있게 한다.

## 2. 다운로드 검증

아래 조건을 모두 통과해야만 적용 단계로 넘어간다.

1. 다운로드 URL이 HTTPS이고 이 저장소의 GitHub 릴리즈 경로 아래에 있다.
2. API가 보고한 크기가 0보다 크고 1GiB 이하이며, 응답·다운로드 결과 크기와 일치한다.
3. GitHub 자산 `digest`의 SHA-256이 올바른 형식이고 다운로드 파일의 해시와 일치한다.
4. 실행 파일 또는 설치 프로그램의 파일 버전이 릴리즈 태그와 일치한다.
5. 포터블 ZIP은 다음 추가 조건을 만족한다.
   - 루트는 `MarkDownEditor.exe`, `web/`, `Runtime/`만 허용한다.
   - `MarkDownEditor.exe`, `web/index.html`, `Runtime/msedgewebview2.exe`가 반드시 존재한다.
   - 경로 탈출, 절대 경로, 중복 엔트리, 10,000개 초과 엔트리, 2GiB 초과 압축 해제량을 거부한다.

GitHub의 digest와 자산은 같은 계정 신뢰 경계에 있다. 릴리즈 계정 자체가 탈취된 상황까지
방어하려면 향후 Authenticode와 별도 키로 서명한 manifest가 필요하다. 개인 키는 저장소나
CI 로그에 넣지 않는다.

## 3. 포터블판 적용

1. ZIP은 `%TEMP%\MarkDownEditor-update.zip`에 내려받는다.
2. 검증 후 앱 폴더의 `.update\payload`에 압축 해제한다.
3. 사용자가 평소 종료 절차를 완료한 `Closed` 시점에만 도우미를 실행한다.
4. 도우미는 메인 프로세스 종료를 기다린 뒤 `web`, `Runtime`, `MarkDownEditor.exe` 순으로
   기존 항목을 `.old`로 바꾸고 새 항목을 이동한다. 실행 파일은 마지막에 교체한다.
5. 일부 교체가 실패하면 이미 바꾼 항목을 모두 원복한다. 성공하면 백업과 `.update`를 지운다.
6. `WebView2Data`는 절대 교체하거나 삭제하지 않고 앱을 재실행한다.

앱 폴더가 쓰기 불가능하면 자체 교체를 시도하지 않고 릴리즈 페이지로 폴백한다.

## 4. 설치판 적용

1. 설치 프로그램은 `%TEMP%\MarkDownEditor-update.exe`에 내려받는다.
2. 공통 해시·크기·파일 버전 검증을 통과한 뒤 업데이트 도우미를 만든다.
3. 사용자가 종료를 확정하면 도우미가 같은 고정 AppId의 설치 프로그램을 현재 사용자 범위에서
   조용히 실행한다.
4. Inno Setup이 프로그램 파일과 Windows의 표시 버전·제거 정보를 함께 갱신한다.
5. 설치가 끝나면 앱을 다시 실행하고 임시 설치 프로그램과 도우미를 삭제한다.

설치판에 포터블 ZIP을 적용하면 Fixed Runtime이 유입되고 제거 정보가 어긋나므로 금지한다.

## 5. 사용자 데이터

- 설치판: `%LOCALAPPDATA%\MarkDownEditor`
- 포터블판: 실행 파일 옆 `WebView2Data`; 해당 위치가 읽기 전용이면 `%TEMP%\MarkDownEditor`

업데이트는 테마·언어·확대 배율·세션 복구·최근 문서·WebView2 캐시를 보존한다. 설치판 제거도
사용자 데이터를 기본 보존하며, 사용자가 원할 때 폴더를 직접 지울 수 있다.

## 6. 필수 검증

- 최신/구버전/404/네트워크 오류와 수동 확인 UI
- URL·크기·digest·버전 오류의 실패 폐쇄
- ZIP 경로 탈출·중복·필수 파일 누락·압축 폭탄 방어
- 포터블 정상 교체, 잠금 재시도, 부분 실패 원복, 데이터 보존, 잔재 정리
- 설치판 다운로드·설치 프로그램 실행·표시 버전 갱신·데이터 보존
- 미저장 종료 취소 시 도우미가 실행되지 않고 이후 평범한 종료에도 예고 없이 적용되지 않는지
- 두 배포판 모두 업데이트 후 정상 실행과 파일 열기
